# Python – FreeCodeCamp Training

A comprehensive Python learning resource covering fundamentals through intermediate concepts with practical projects and challenges.

## 📚 Course Structure

### Module 0: Setup
- **environment_check.py** – Verify your Python environment is properly configured

### Module 1: Basics
- Variables and data types
- Type casting
- Basic operations

### Module 2: Control Flow
- Conditional statements (if/elif/else)
- Loops (for/while)
- Break and continue statements

### Module 3: Functions
- Defining and calling functions
- Function arguments and parameters
- Return values
- Lambda expressions

### Module 4: Data Structures
- Lists – ordered, mutable sequences
- Tuples – ordered, immutable sequences
- Sets – unordered, unique collections
- Dictionaries – key-value pairs

### Module 5: Strings
- String methods and manipulation
- String formatting
- String slicing and indexing

### Module 6: File I/O
- Reading files
- Writing files
- File operations

### Module 7: Error Handling & Exceptions
- Try/except blocks
- Custom exceptions
- Exception handling best practices

### Module 8: Object-Oriented Programming
- Classes and objects
- Inheritance
- Encapsulation

### Module 9: Modules & Packages
- Built-in modules (datetime, math)
- Importing and using modules
- Creating packages

### Module 10: Standard Library
- OS and sys modules
- Random and collections modules

## 🚀 Projects

### 1. File Organizer
Automatically organize files into folders based on file type.

### 2. Number Guessing Game
Interactive game where the computer picks a number and you guess it.

### 3. Password Generator
Generate secure random passwords with customizable criteria.

## 🎯 Challenges

Test your knowledge with coding challenges that reinforce key concepts across all modules.

## 🛠️ Setup

1. Clone or download this repository
2. Ensure Python 3.7+ is installed on your system
3. Run individual scripts to explore topics:
   ```bash
   python 01_basics/01_hello_world.py
   ```

## 📖 How to Use

- **For Learning**: Work through each module sequentially, reading the notes and running the example scripts
- **For Practice**: Complete the challenges in `12_challenges/`
- **For Projects**: Build practical applications in `11_projects/`

## 📝 Notes

Each module folder contains a `notes.md` file with explanations, best practices, and additional resources.
